The key is stored in this browser profile and sent to your Synchro server for this playback session. Cloud modes use this one provider key. Full cloud mode also sends audio and generates the voice through that provider. API usage is billed to your account.

HY-MT2 translates plain text. Cloud Gemma through the same provider prepares Latin names and numbers for Silero when needed. That extra request is billed separately; no local LLM is used.

YouTube video plays directly in its native player; the server fetches audio only. Seeking restarts translation at the selected position. Other sites use a separate player with tab recording and no fixed duration limit.

Updates

Checks once a minute. Updates wait until YouTube translation or the separate player is closed. Put new files in the same extension folder.

The optional GitHub updater checks Synchro Releases every 15 minutes and preserves this installation's server and extension identity. Install it once with tools/install-updater.ps1 from the project. An unpacked extension cannot overwrite its own files.
